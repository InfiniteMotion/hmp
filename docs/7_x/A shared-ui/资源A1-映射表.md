## 5. 构建配置配套（Res 访问器生成）

`composeResources` 的 `Res.*` 访问器生成需要 `org.jetbrains.compose` Gradle 插件（版本 = CMP `composeMultiplatform`，当前 1.8.2），当前 shared-ui 未应用该插件（仅手动依赖 CMP 组件库）。**启用时机**：第 1 步迁设计系统前（首个 `Res.*` 消费点出现前）必须补上：

```toml
# gradle/libs.versions.toml [plugins]
compose-multiplatform = { id = "org.jetbrains.compose", version.ref = "composeMultiplatform" }
```

```kotlin
// shared-ui/build.gradle.kts plugins
alias(libs.plugins.compose.multiplatform)
```

> 插件带入的组件依赖与现有手动 `jetbrains-compose-*` 依赖同坐标同版本，Gradle 自动去重，无冲突。
