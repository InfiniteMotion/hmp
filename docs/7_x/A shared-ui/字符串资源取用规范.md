# 字符串资源取用规范

> 适用范围：`shared-ui`（Compose Multiplatform）全部 UI 文案。
> 本文取代此前「就近随手取串」的松散做法；新增代码必须遵循，存量按 §6 迁移。

***

## 1. 机制约束（规范的地基）

Compose 只提供了一个解析入口 `stringResource`，它依赖**组合环境**（`Locale` / 主题 / 密度），且环境变化时会自动重算 —— 因此**只能在 composable 内调用**。

非 composable 侧只有一个口：挂起 `getString`。它走的是 **`getSystemResourceEnvironment()`（系统环境）**、且结果一经调用即定格。由此推出三条硬约束：

1. **非 composable 无法同步取串。** 顶层 `val` 初始化、`init {}`、纯函数里根本调不了 —— 这是「目录常量 / 格式化函数」必须改结构的根因。
2. **环境会分叉。** 一旦将来引入应用内语言覆盖（覆盖 Compose `Locale`），`stringResource` 会跟随、`getString` **不会** —— 同一屏出现两种语言。
3. **结果会冻结。** 解析结果存进 `StateFlow` / 领域模型后，切语言不更新。

**结论：表示与解析必须分离。** 非 composable 只携带「引用 + 参数」，解析一律推迟到唯一的解析场所 —— 组合期。

***

## 2. 三种承载方式

| 场景 | 用什么 | 说明 |
|---|---|---|
| composable 内 | `stringResource(res, *args)` | 首选，无需包装 |
| **非 composable 携带文本** | **`UiText`** | 数据类 / 枚举 / 顶层常量 / VM 状态 / 领域回调 |
| 终点必须是非 Compose 输入 | 挂起 `getString` | 最晚解析、必须在协程里；仅当消费方强制要求纯 `String` |

「终点必须是非 Compose 输入」的典型：领域模型字段（`:shared` 不依赖 compose-resources）、平台 API（通知 / 分享面板用的也是 `androidMain/res` 另一套资源）。

***

## 3. UiText

定义位置：`com.hearablemusic.player.ui.common.text.UiText`

```kotlin
sealed interface UiText {
    /** 资源引用 + 位置参数（对应 stringResource(res, *args)）。 */
    data class Res(val res: StringResource, val args: List<Any> = emptyList()) : UiText
    /** 不可译原文（LLM 输出、歌名/歌手名、endpoint、用户输入等）。 */
    data class Raw(val text: String) : UiText
}

fun StringResource.asUiText(vararg args: Any): UiText
@Composable fun UiText.asString(): String      // 唯一解析场所
```

**约定**

- **参数随引用一起走，绝不在非 composable 侧预拼接文本。** 语序、复数、量词随语言变化，预拼死等于放弃本地化能力。
  反例：`footer = "累计 ${count} 次"`；正例：`UiText.Res(Res.string.card_total_plays, listOf(count))`。
- **参数可嵌套 `UiText`**，解析时递归展开。用于「为你推荐 · %1$s」这类带本地化子串的模板。
- **不可译内容一律 `Raw`**（LLM 生成文本、歌名、endpoint、URL、纯数字），不要硬塞进资源表。
- 资源侧的占位符约定沿用 T2：`%1$s` / `%1$d` **原样保留、不可删改**。

## 4. 决策树

```
在 composable 内？
├─ 是 ──► stringResource(res, *args)
└─ 否
   ├─ 文本会进数据类 / 枚举 / 顶层常量 / VM 状态？
   │   ├─ 是 ──► UiText（Res 或 Raw）      ← 默认
   │   └─ 否
   │      ├─ 消费方强制要求纯 String？
   │      │   ├─ 是 ──► suspend getString(...)（协程内，最晚解析）
   │      │   └─ 否 ──► UiText
   └─ 是 Android 平台 API ──► context.getString(R.string.x)（androidMain/res 另一套）
```

***

## 5. 明确不在范围内的两种形态

以下**保留 `StringResource`**，不要包 UiText：

1. **资源选择器**：`private fun HazeMaterialPreset.labelResId(): StringResource`
   它是「输入枚举 → 输出资源」的映射函数，返回的是**资源本身**，调用方在同一渲染周期内立即 `stringResource(...)` 消费。语义上不是「文本载体」。
2. **composable 内局部值**：`val iconDesc: StringResource = if (isFacePage) Res.string.x else tab.label`
   它就是当前组合期内的一个临时值，直接用 `stringResource` 解析。

判据：**资源是否被跨帧/跨层携带**。会被长期持有（数据类字段、状态、常量表）→ UiText；只在一次渲染里过手 → `StringResource`。
