# 阶段一切换前基线：旧版 UI 截图存档 + 关键交互清单

> 依据：[`../方案.md`](../方案.md) C11 / §7 第 0 步
> 用途：**唯一**的"旧行为"对照依据。旧 feature-ui 冷死后无法运行时对照，验收以本存档为准。
> 拍摄时点要求：**必须在依赖替换之前**（拍摄当前 master 构建的真旧版）。

## 一、截图存档操作指引

1. 在 `master`（v6.13.1 基线）构建 Debug 包并安装到真机；
2. 按下文「二、页面截图清单」逐页截图（建议同时覆盖浅色/深色主题各一轮）；
3. 系统弹窗类（权限引导、分享面板、文件选择器）出现时一并截图；
4. 截图放入本目录 `screenshots/` 子目录，命名规则：
   - `NN_页面名_主题.png`，如 `01_home_light.png`、`01_home_dark.png`
   - 对话框：`NN_页面名_dialog_对话框名.png`，如 `08_setting_dialog_timer.png`
5. 交互过程可用屏幕录制补充（可选，放 `recordings/`）。
