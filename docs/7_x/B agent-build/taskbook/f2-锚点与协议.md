## 6. 经验与踩坑

- **协议形状要提前备**：M2 时就把 M4 需要的 assistant `tool_calls` 回传形状补进 DTO。若等 M4 才发现，协议层要返工一轮。
- **runTest 虚拟时间会误触发真实超时逻辑**——凡带 `withTimeout` 的流式代码，单测必须显式禁用超时。
- **`onPreviewKeyEvent` vs `onKeyEvent`**：全局快捷键挂捕获阶段会吃掉所有文本输入的对应字母。全局键应挂冒泡阶段，让输入框先消费。
- **`@SerialName` 漏标不报错**：`finishReason` 缺注解时非流式响应解码恒为 null，静默失败——DTO 字段命名与 JSON 不一致时必须显式标注。
