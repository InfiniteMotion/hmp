# T2 · 字符串收拢 · 待译清单（14 语言）

> **用途**：T2 要求 agent 子树 UI 面向文案全部进 `strings.xml`，且 **14 个语言文件键集合一致**。
> 本清单跟踪每个新键的译文状态。**14 语言已全部填好**：`values`（英文）/ `values-zh`（中文）由 agent 撰写；
> 其余 12 语言（ar/de/es/fr/hi/id/ja/ko/pt/ru/th/vi）由 agent 自行翻译并已写入对应 `values-xx/strings.xml`。
>
> **复核方式**：下表 `英文` / `中文` 列为源文，是各键的权威键名录；**其余 12 语言的译文已落盘到
> `values-xx/strings.xml`**（未在本表重复粘贴，避免与 XML 双份维护）。如需微调某条译文，直接改对应
> `values-xx/strings.xml` 即可（或告知我批量替换）。占位符已逐语言校验与源文一致。
>
> **占位符约定**：`%1$s` / `%2$s` / `%3$d` 等位置参数在翻译时**原样保留、不可删改**，仅翻译周围文字。
> 例：`今日 %1$s · 剩余 %2$s · %3$d%` → 英文 `Today %1$s · Remaining %2$s · %3$d%`。
>
> **引用约定（踩坑记录·重要）**：Compose Resources 生成的访问器是 **`Res.string` 上的扩展属性**
> （`public val Res.string.KEY: StringResource by lazy`，位于 `…generated.resources` 包）。跨包引用
> `Res.string.KEY` **必须逐键 import**：`import com.hearablemusic.player.ui.generated.resources.<key>`，
> 否则编译报 `Unresolved reference '<key>'`。批量抽取时务必同步补齐每个用到的键的 import
> （本仓 T2 首轮曾因漏 import 导致 `:shared-ui:compileKotlinDesktop` 报出上百条 Unresolved）。

> - `ChatViewModel` 失败兜底：「（暂时没连上伙伴，稍后再试）」

>
> - **（cards）非 composable 构造/格式化 helper**：`HelloCardFormat.formatGeneratedAgo / formatAvgMinutes / TimePhase.label`、`HelloCardAnniversary.resolveVisual()`（label / badge / footer 文案）、`HelloCardSingleTrack.buildSingleTrackMeta()`（label / footer）、`HelloCardRadioStatus` 卡构造器里的 `actionText`（「播放中」/「已暂停」）、`HelloCardGreeting` 的 `${phase.label}好～`、`HelloCardNarrative` 的 `${timeRange.zhName()}听歌报告` 与 `日均听歌 …`。这些文案都在非 composable 函数/顶层常量里生成，属同一类延后项。
>
> 这些串将随「非 composable 取串」能力（见 ideas / 后续 T2 收尾）一并处理，不阻塞当前可抽取部分。
>
> **不抽取（非中文/技术标识）**：`agentLabelFor()` 返回的是 Agent 类名（`MasterAgent`/`HelloSubAgent`/`EnrichSubAgent`/`RadioSubAgent`，英文标识，非可译文案）；`"System Prompt"` 卡片标题、`"API Key"` 标签、以及端点/模型示例占位（`https://api.deepseek.com/v1`、`sk-...`、`deepseek-chat / gpt-4o-mini / ...`）均为英文技术串，保留原样。
