## 3. 与方案草案（§5.3/§5.4）的差异记录

| # | 草案 | 冻结版 | 理由 |
|---|---|---|---|
| 1 | `currentMusic` | `currentPlayingMusic` | 跟随现有命名，页面迁移零改动 |
| 2 | `positionMs` / `durationMs` / `timerRemainingMs` | `currentPosition` / `duration` / `timerRemaining` | 同上 |
| 3 | `queue: StateFlow<List<MusicInfo>>` | `currentPlaylist` | 同上 |
| 4 | `likeStatus: StateFlow<Set<Long>>` | `likeStatus: StateFlow<Boolean>` | 实际语义是「当前曲目」收藏态（MusicController:170），无集合形态调用点 |
| 5 | `play(music)` / `playAll(list, mode)` | `playWith(music)`（suspend）/ `addAllToPlaylistInOrder` + `addAllToPlaylistByShuffle` | 现有入口形态；mode 分叉已固化为一对方法 |
| 6 | `setPlaybackMode(mode)` | `togglePlaybackModeByOrder()` | UI 唯一调用形态是三态循环切换 |
| 7 | `setLike(musicId, liked)` | `updateMusicLikedStatus(music, liked)` | 实际签名携带 MusicInfo（内部联动歌单） |
| 8 | `playNextInQueue(music)` | `addToNextPlay(music)` | 现命名 |
| 9 | `removeFromQueue` / `clearQueue` | `removeFromPlaylist` / `clearPlaylist` | 现命名 |
| 10 | 草案缺 | 补：`isMiniPlayerVisible`、`currentMusicLabels`、`currentMusicLyrics`、音效 5 状态 + 6 方法、`playHeartMode`、`getLikedStatus/getMusicLabels/getMusicLyrics`、`start/stopProgressTracking` | C15 全量盘点补全项 |
| 11 | PlatformServices 草案 6 组 + MediaSession 并入 | 冻结 5 组；MediaSession/AppLifecycle 不设组 | 两者在 UI 均无调用点（MediaSession 全在 core-player 服务内部；无 moveTaskToBack/finish 调用）。阶段二如需暴露按流程增补 |

## 4. 盘点到但不进接口的 MusicController 成员

| 成员 | 理由 |
|---|---|
| `toastEvent: SharedFlow<UiEvent.ShowToast>` | Android UI 无消费点（desktop 消费）；`UiEvent` 类型位于 core-player，不可进 commonMain。跨端提示属阶段二议题 |
| `bindService/unbindService/bindPlayControl/setTargetActivityClass/release` | Android 服务装配细节，属 app 壳层职责（C12），非 UI 契约 |
| `isMusicLoaded` / `preloadCurrentMusicInfo` / `updateLyricLine` | 无 UI 调用点（内部或服务回调用） |
| `getCurrentEqualizerPreset/getBassBoostLevel/isSurroundSoundEnabled/getReverbPreset/getCurrentEqualizerBandLevels`（同步 getter） | UI 只消费 StateFlow 形态（AudioEffectViewModel），同步 getter 无调用点 |

## 5. 实现落点（后续步骤，本步不实施）

- **Android**：`android:app` 提供 `PlaybackController` 实现（委托 Media3 `MusicController`）与 `PlatformServices` 五组实现，Koin 注册（C12）。
- **Desktop**：`desktop:app` 提供对称实现（适配 FFmpeg 引擎；PlatformServices 给空/等价实现）（D12）。
- **接线时机**：PlaybackController 真实接线在第 3 步（Player 页迁移时）；PlatformServices 随对应页面（MainScreen/设置页）迁移接线。
