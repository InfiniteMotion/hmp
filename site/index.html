沉浸氛围

视觉体验

不只是播放页——整个应用都笼罩在随音乐实时变化的氛围光影中。从专辑封面提取色彩，生成持续流动的动态背景。三种风格可选：流体极光、沉浸光斑、复古模糊。亮色与暗色模式下各有不同的氛围表达。

色彩提取 流体极光 全应用沉浸 亮暗双模

通透质感

UI 设计

底部导航栏、迷你播放器、对话框——HMP 的核心交互区全部采用大圆角毛玻璃卡片，悬浮于动态背景之上。模糊半径、噪点纹理、透明度均可调节。三端用的是同一套 Compose 界面，观感一致。

Haze 毛玻璃 可调节参数 三端一致

Agent · 协作

曲库认识、智能推荐这些能力，如今都收进了一套 agent 体系：MasterAgent 是唯一大脑，处理对话、调度后台；电台、曲库认识、门面问候是三个各自独立的执行域，各有模型连接与上下文预算，只共用基建。

唯一大脑 三个执行域 30 个原子工具 记忆只存设备

自适应布局

平台

业务逻辑、数据层与界面层都通过 Kotlin Multiplatform 在三平台共享。手机用底部胶囊导航，桌面端在宽屏下自动切换为侧边导航栏，窗口缩窄时退回底部布局。
