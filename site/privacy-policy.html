隐私政策

最后更新：2026 年 7 月 5 日

概述

HMP（Hearable Music Player）是一款纯本地音乐播放器。我们高度重视您的隐私，本政策说明了我们的数据处理方式。HMP 不收集、不上传任何用户数据，所有功能均在设备本地运行。

数据收集

HMP 不收集以下任何数据：

  • 个人身份信息
  • 音乐文件内容或播放历史
  • 设备标识符或使用行为数据
  • 位置信息

网络使用

HMP 在以下场景使用网络，均需用户主动触发：

  • AI 推荐功能 — 向用户自行配置的 API 服务发送请求，HMP 不内置任何第三方账号或密钥，不存储 API 响应内容
  • 歌词/封面下载 — 请求第三方公开数据源，下载内容存储在设备本地

本地存储

以下数据仅存储在您的设备本地，不会离开您的设备：

  • 播放列表与歌曲收藏
  • 播放偏好与均衡器设置
  • 应用配置与主题选择
  • 下载的歌词和封面图片

权限说明

HMP 申请的权限仅用于核心功能：

  • READ_MEDIA_AUDIO — 读取设备上的音频文件
  • INTERNET — AI 推荐、歌词/封面下载（需用户主动触发）
  • FOREGROUND_SERVICE — 后台音乐播放
  • POST_NOTIFICATIONS — 播放控制通知

第三方服务

HMP 不集成任何第三方分析、广告或追踪 SDK。AI 推荐功能使用的 API 端点由用户自行配置，HMP 不对第三方服务的隐私政策负责。

儿童隐私

HMP 不针对 13 岁以下儿童，也不会有意收集任何儿童的个人信息。

政策变更

如本隐私政策有重大变更，将在应用内或本页面通知用户。继续使用 HMP 即表示您接受更新后的政策。
